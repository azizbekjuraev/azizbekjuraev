## 🚀 Octopos — Restaurant POS Platform

[**octopos.uz**](https://octopos.uz/) — production work I delivered at [@yeahuz](https://github.com/yeahuz)
**Stack:** React · TanStack Query · Go

A real point-of-sale platform **live in restaurants across Namangan, Uzbekistan and Seoul, South Korea**, running service every day.

**What I helped ship:**
- **Three coordinated apps** — Dashboard (owner analytics), POS (cashier terminal), Kitchen display — sharing one codebase
- **Shared package layer** — single source of truth for API clients and UI components consumed by all three apps; features land in one place and propagate everywhere
- **Offline-first by design** — POS and Kitchen apps keep operating when the internet drops; orders queue locally and sync seamlessly when connectivity returns (because a restaurant can't stop serving guests when the WiFi blinks)
- **Go backend** with **TanStack Query** on the frontend for predictable async state and cache invalidation
